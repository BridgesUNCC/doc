Detailed Description

This is a helper class for accessing actor-movie data from Wikidata.

This object is generally not created by the user, to see how its created check out bridges::data_src_dependent::data_source::get_wiki_data_actor_movie()

See also
For an example, check out https://bridgesuncc.github.io/tutorials/Data_WikiDataActor.html
